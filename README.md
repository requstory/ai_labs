# ai_labs
To carry out Ai experiments for organisations we work for

## Sites

- [Workout Guide](https://requstory.github.io/ai_labs/) — static exercise illustration gallery (`workout-guide/`), mirrored from [bryllim/workout-guide](https://github.com/bryllim/workout-guide) and deployed via GitHub Pages (see `.github/workflows/pages.yml`).
- [Coach](https://requstory.github.io/ai_labs/coach/): personal 24-week training plan app for iPhone, built on the Workout Guide animations (`workout-guide/apps/site/src/coach/`). Open it in Safari and use Share → Add to Home Screen.
